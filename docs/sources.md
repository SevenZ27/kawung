# Sources for the motif notes

Each note in the app is a short paraphrase. I opened every page below on 13 Sep 2026 and only kept what the page says.

| Motif | What the note uses | Source |
|---|---|---|
| Kawung | four ellipses around one centre, known as "keblat papat lima pancer", listed as a batik larangan of the Yogyakarta palace | Keraton Yogyakarta, "Motif Batik Larangan Keraton Yogyakarta" (19 Mar 2018), https://www.kratonjogja.id/kagungan-dalem/12-motif-batik-larangan-keraton-yogyakarta/ |
| Parang | curved diagonal lines, rules for wearing it as batik larangan became strict under Sri Sultan Hamengku Buwono VIII | same page as above |
| Truntum | created by Kanjeng Ratu Kencana, wife of Sunan Paku Buwana III, depicts sincere love | Museum Sonobudoyo Yogyakarta, "Mengenal Batik Khas Jogja: Filosofi di Balik Keindahan Motifnya", https://sonobudoyo.jogjaprov.go.id/id/tulisan/read/mengenal-batik-khas-jogja-filosofi-di-balik-keindahan-motifnya |
| Ceplok | symmetric geometric pattern with flower or star elements | same page as above |

Also read while checking kawung: Dinas Kebudayaan DIY, "Batik Kawung" (2 Jun 2022), https://budaya.jogjaprov.go.id/berita/detail/1152-batik-kawung. It describes rounded kawung-fruit shapes arranged geometrically. Not quoted in the app.

The drawings in the app are geometric interpretations. They follow the basic structure described above and do not copy a specific cloth.
